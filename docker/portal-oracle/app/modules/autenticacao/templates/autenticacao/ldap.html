Como funciona

  • O administrador é sempre local (ficheiro data/admin.json).
  • Cada utilizador tem um tipo de autenticação (Configuração → Utilizadores): Local (password no portal) ou LDAP.
  • LDAP: a conta de serviço procura o utilizador com o filtro; depois o portal confirma a password com um bind do próprio utilizador.
  • O perfil (o que pode fazer) é sempre o do portal.
  • Cada login fica no registo de Acessos.
