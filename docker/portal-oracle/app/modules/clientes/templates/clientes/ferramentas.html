Serviço Oracle sem internet (python-oracledb)

{{ wheels|length }} wheel(s) no portal · o setup.sh --oracle instala a partir daqui

Num cliente sem internet, o setup.sh --oracle pede ao portal os wheels compatíveis com o Python e a arquitetura do cliente e instala-os com pip --no-index; só se não houver nenhum é que tenta a internet. Firewall (serviço Oracle do agente)

firewalld com ipset, ufw, gestão pelo portal

O portal liga-se a cada cliente na porta do serviço Oracle do agente (8795/tcp). Abra-a só às origens do portal com um ipset. Também pode fazê-lo — e gerir zonas, portas, serviços, regras ricas, ipsets ou regras ufw — na aba Firewall de cada cliente.

{{ cmd('Tudo de uma vez pelo setup.sh (ipset em todas as zonas ativas)', 'sudo bash /tmp/setup-agente.sh --oracle --origens " /24" --abrir-firewall --ipset ipset-agente-portal') }} {{ cmd('Permitir que o portal altere a firewall (aba Firewall)', 'sudo agente-portal configurar --gerir-firewall', 'Sem isto o portal só lê o estado. Desligar: sudo agente-portal configurar --sem-gerir-firewall. Os utilizadores precisam da permissão clientes.firewall.') }} {{ cmd('firewalld: zonas ativas', 'sudo firewall-cmd --get-active-zones') }} {{ cmd('firewalld: criar o ipset', 'sudo firewall-cmd --permanent --new-ipset=ipset-agente-portal --type=hash:net') }} {{ cmd('firewalld: juntar origens ao ipset', 'for ip in /24; do sudo firewall-cmd --permanent --ipset=ipset-agente-portal --add-entry=$ip; done') }} {{ cmd('firewalld: abrir a porta ao ipset (em cada zona ativa)', 'for z in $(sudo firewall-cmd --get-active-zones | grep -v "^ "); do\n sudo firewall-cmd --permanent --zone=$z --add-rich-rule=\'rule family="ipv4" source ipset="ipset-agente-portal" port port="8795" protocol="tcp" accept\'\ndone\nsudo firewall-cmd --reload && sudo systemctl restart firewalld') }} {{ cmd('firewalld: ficheiro do ipset', 'sudo cat /etc/firewalld/ipsets/ipset-agente-portal.xml') }} {{ cmd('firewalld: ver', 'sudo firewall-cmd --info-ipset=ipset-agente-portal; sudo firewall-cmd --list-all --zone=') }} {{ cmd('firewalld: retirar uma origem', 'sudo firewall-cmd --permanent --ipset=ipset-agente-portal --remove-entry= && sudo firewall-cmd --reload && sudo systemctl restart firewalld') }} {{ cmd('ufw: abrir a porta a uma origem', 'sudo ufw allow from to any port 8795 proto tcp comment agente-portal') }} {{ cmd('ufw: ver / apagar', 'sudo ufw status numbered\nsudo ufw delete ') }}
