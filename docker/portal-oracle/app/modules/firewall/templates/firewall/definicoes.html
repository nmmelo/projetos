Permissões do portal

O portal (utilizador de serviço) usa sudo -n firewall-cmd / sudo -n ufw e lê o registo com journalctl (comandos exatos), autorizados em /etc/sudoers.d/{{ instancia }}-firewall:

sudo instalar.sh --firewall {{ instancia }} on      # autorizar
sudo instalar.sh --firewall {{ instancia }} status  # ver
sudo instalar.sh --firewall {{ instancia }} off     # retirar

Iniciar, parar e reiniciar o serviço firewalld faz-se no módulo Sistema (instalar.sh --servicos {{ instancia }} +firewalld).
